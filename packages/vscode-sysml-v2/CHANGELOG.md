# Changelog

## 0.2.0 — 2026-09-30

- New: live preview panel for `.sysml` files. Run **SysML v2: Open Preview**
  from the command palette, the editor title bar, or the Explorer context
  menu; the diagram re-renders as you edit.
- Example models: `examples/sysml/` (17 `.sysml` files) and
  `examples/markdown/demo.md`.

## 0.1.0 — 2026-09-29

- First round: a ```sysml-v2 fenced code block in Markdown renders as a
  diagram in VS Code's built-in Markdown preview, via `mermaid-sysml-v2`.
  No syntax highlighting, no pan/zoom, no theme-following yet — see the
  README's "Known limitations."
